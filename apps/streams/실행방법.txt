[Streams 실행 방법]

1) 폴더 이동
cd apps/streams

2) 패키지 설치
npm install

3) 개발 실행(클라이언트+서버 동시 실행)
npm run dev

4) 접속 주소
- 진행자/참가자 공통 기본 접속: http://<노트북IP>:5173
- 소켓 서버: http://<노트북IP>:3000

5) 진행자 로그인
- PIN 입력 후 로그인
- PIN 변경: 환경변수 STREAMS_HOST_PIN 사용

6) 학생 식별 규칙(studentKey)
- 학생은 socket.id가 아닌 studentKey(예: 2-15-홍길동, 15-홍길동)로 식별됨
- 새로고침/재접속 시 동일 studentKey로 입장하면 board, score, 배치상태 복구됨

7) 성능 최적화 핵심
- 학생 배치 시 전체 상태 브로드캐스트를 하지 않음
- 학생 본인: myBoardUpdated만 수신
- 진행자: studentPlaced(해당 학생 변경분)만 수신
- 숫자 뽑기 때만 numberDrawn을 room 전체 전송

8) 배포(프로덕션)
npm run build
npm run start
- 접속: http://<노트북IP>:3000
