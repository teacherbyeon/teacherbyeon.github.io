[Streams 실행 방법]

1) 폴더 이동
cd apps/streams

2) 패키지 설치
npm install

3) 개발 실행(클라이언트+서버 동시 실행)
npm run dev

4) 접속 주소
- 진행자/참가자 공통 기본 접속: http://<노트북IP>:5173
- 소켓 서버: http://<노트북IP>:3000

5) 진행자 로그인
- PIN 입력 후 로그인
- PIN 변경: 환경변수 STREAMS_HOST_PIN 사용

6) 조커 옵션 확인
- 진행자 게임 설정 화면에 "조커 포함 여부" 체크박스가 있음 (기본 ON)
- 게임 진행 화면에도 "다음 새 게임에 조커 포함" 체크박스가 표시됨
- 체크 해제 시 J카드는 비활성화되고 실제 뽑기 덱에서 제외됨

7) 참가자 접속 URL/QR
- 진행자 설정 화면에서 "참가자 접속 URL"에 숫자 IP URL 입력
  예) http://192.168.0.15:5173
- 게임 시작 후 진행자 화면에 동일 URL과 QR 코드가 표시됨
- 학생은 QR 스캔 또는 URL 직접 입력 후 참가자로 입장

8) 배포(프로덕션)
npm run build
npm run start
- 접속: http://<노트북IP>:3000
