# 수업 벽보드 MVP

요구사항(수업코드/QR, 교사/학생 분리 화면, 별명 기반 좌석, 손풀이 썸네일, 전체 보기/해제, 벽보드 전환)을 확인할 수 있는 실행 버전입니다.

## 실행 방법 (교사 노트북)

1. Node.js 18+ 설치
2. 의존성 설치

```bash
cd apps/class-wallboard
npm init -y
npm i express socket.io
```

3. 서버 실행

```bash
node server.js
```

4. 접속 URL
   - 역할 선택: `http://교사노트북IP:4310/role.html`
   - 교사 벽보드 바로접속 예: `http://교사노트북IP:4310/board.html?role=teacher`
   - 학생 벽보드 바로접속 예: `http://교사노트북IP:4310/board.html?role=student&code=수업코드`

## 페이지 흐름

1. `role.html` : 역할 선택
2. `teacher-auth.html` : 교사 PIN 인증/변경(교사만)
3. `join.html` : 수업 코드 생성/입장
   - 교사 생성 시 수업 이름 기본값 `yymmdd`
   - 학생은 수업 목록 선택 없이 수업 이름+코드 직접 입력
4. `past-classes.html` : 과거 수업 조회/삭제(교사만)
5. `profile.html` : 학생 프로필 입력(학생만)
6. `board.html` : 손풀이 제출 + 현재 벽보드
7. `manage.html` : 교사 전용 학생 관리(실명/제출현황/다운로드)

## 현재 MVP 기능

- 교사용 수업 이름 기준 수업 생성/관리 (코드는 입장용 6자리 숫자)
- 교사 PIN 인증(교사용 제어/집중보기/히스토리 전환 보호)
- 교사 PIN 기본값 `123456`, 변경 기능 제공(전 수업 공통 PIN)
- 학생은 교사가 안내한 수업 이름+코드 직접 입력으로 입장
- 교사/학생 화면 분리 (페이지 분리)
- 교사용 전용 학생관리 화면 분리(`manage.html`)
- 교사용 관리 화면은 벽보드와 분리되어 독립 사용
- 과거 수업은 `past-classes.html`에서 조회/삭제
- 학생 프로필(반/학번/이름/별명) 입력
- 중복 별명 방지(동일 수업 내 기존 사용자와 충돌 시 차단)
- 교사가 벽보드 제목 생성
- 새 벽보드 생성 시 현재 로그온/참여 학생 자리 자동 유지
- 학생이 손풀이 사진 업로드 (모바일 촬영 버튼과 파일 선택 버튼 분리)
- 학생 파일 제출은 이미지/PDF/기타 파일 지원
- 교사는 제출 파일 다운로드 가능(학생 화면에는 다운로드 미제공)
- 썸네일 생성 후 별명 자리 카드에 표시
- 교사는 썸네일 우측 상단 X 버튼으로 즉시 삭제 가능
- 썸네일 클릭 시 확대, 다시 클릭 시 축소
- 교사가 확대 해제 버튼으로 전체 해제
- 벽보드 히스토리 탭으로 문항별 벽보드 전환
- 문항 탭마다 업로드 진행수(제출/전체) 표시
- 미업로드 인원이 5명 이하일 때만 미업로드 별명 목록 노출
- 교사용 관리화면에서도 문항 히스토리 선택 가능
- 관리화면 문항 선택은 학생 벽보드 활성 문항과 독립적으로 조회
- 출석/제출 현황 CSV 내보내기
- 교사용 테마/전자칠판용 테마 전환
- 전체 UI를 카드형 레이아웃으로 개선
