[교실 자리배치 프로그램 사용방법]

1) 프로그램 실행 방법
- 압축을 푼 뒤, "index.html" 파일을 더블클릭하세요.
- 인터넷 없이도 모든 핵심 기능(좌석 편집, 엑셀/CSV 불러오기, 저장/불러오기, 인쇄)이 동작합니다.
- 같은 폴더에 실제 동작하는 "xlsx.full.min.js" 파일이 있어야 엑셀(.xlsx) 파일을 바로 읽을 수 있습니다.

2) 학생 명단 파일 형식
- 필수 헤더: 번호, 이름
- 선택 헤더:
  성별, 고정좌석, 앞자리우선, 뒤자리우선, 교탁근처우선, 시력배려, 키큼,
  분리대상, 같은줄금지, 같은열금지, 인접금지, 메모

- 헤더 예시(첫 줄)
번호 | 이름 | 성별 | 고정좌석 | 앞자리우선 | 뒤자리우선 | 교탁근처우선 | 시력배려 | 키큼 | 분리대상 | 같은줄금지 | 같은열금지 | 인접금지 | 메모

- 고정좌석 입력 방법
  - "고정좌석" 칸에는 좌석 ID가 아니라 **좌석 라벨**을 입력합니다.
  - 기본 좌석 라벨 형식은 `행열` 숫자입니다. 예) 1행 1열은 `11`, 2행 3열은 `23`
  - `1-1`처럼 하이픈(-)이 들어가도 자동으로 `11`로 인식합니다.

- 예시 데이터(둘째 줄)
1 | 김민수 | 남 | 11 | 예 |  |  |  |  | 5,8 |  |  | 12 | 안경 착용

3) 기본 사용 순서
(1) 학생 파일(.xlsx 또는 .csv) 불러오기
(2) "자리 다시 생성"으로 기본 좌석 만들기
(참고) 우측 카드 제목을 누르면 카드별 접기/펼치기가 가능합니다.
(3) 모드 버튼으로 좌석 위치 편집
    - 선택 모드: 좌석 선택/드래그
    - 좌석 추가 모드: 빈 공간 클릭
    - 좌석 삭제 모드: 좌석 완전 삭제
    - 좌석 사용불가(X) 모드: 사용 불가 처리
    - 학생 배정 모드: 학생 선택 후 좌석 클릭
    - 자리 바꾸기 모드: 좌석 2개를 순서대로 클릭
(4) 필요 시 "랜덤 배정", "조건 반영 자동 배정", "번호순 배치" 사용
(5) 수동으로 미세 조정

3-1) 결시 체크 / 결시 현황 문구
- 학생 목록에서 각 학생의 결시 구분(병결/인정결/미인정) 체크로 결시 상태를 표시합니다.
- 학생 목록 영역은 오른쪽 아래 모서리를 마우스로 드래그하여 높이를 조절할 수 있습니다.
- 결시 학생은 좌석/학생 목록에서 시각적으로 강조됩니다.
- 결시 현황 문구는 자동 생성되며 "결시 현황 복사" 버튼으로 복사할 수 있습니다.
- 자동 문구 형식:
  - 결시 있음: 재적 n명 결시 n명 결시자: n번 이름, n번 이름
  - 결시 없음: 재적 n명 결시 0명

4) 저장 / 불러오기 방법
- "배치 저장(JSON)" 버튼으로 현재 상태를 파일로 저장합니다.
- "배치 불러오기(JSON)" 버튼으로 저장한 파일을 다시 불러옵니다.
- 좌석 위치, 교탁 위치, 학생 배정 상태, 출력 문구 등이 함께 저장됩니다.

5) 출력 방법
- "인쇄하기(A4)" 버튼을 누르세요.
- 시험지 배치 확인용으로 "시험용 인쇄(A4)" 버튼을 사용할 수 있습니다.
- 시험용 인쇄 좌석표 셀에는 번호/이름이 함께 출력되며, 결시 체크 시 결시 사유도 함께 표시됩니다.
- 시험용 인쇄의 결시자 현황은 페이지 맞춤을 위해 "번호(결시구분)" 형식으로 표시되며, 결시 인원이 많으면 글자 크기가 자동으로 줄어듭니다.
- 결번 계산은 학번의 시작 번호(예: 3301 또는 30301)를 기준으로 자동 계산됩니다.
- 인쇄 창에서 프린터 또는 PDF 저장을 선택할 수 있습니다.

6) 주의사항
- "자리 다시 생성"은 기존 좌석 배치를 지웁니다. 반드시 저장 후 진행하세요.
- 상단에 "저장되지 않은 변경사항"이 보이면 먼저 저장하세요.
- 학생 수가 좌석 수보다 많으면 오류가 표시됩니다.

7) 문제 발생 시 확인 사항
- 학생 파일 첫 줄 헤더에 "번호, 이름"이 있는지 확인하세요.
- 번호가 중복되었는지 확인하세요.
- 분리대상/인접금지 등에 없는 번호를 입력했는지 확인하세요.
- .xlsx 불러오기 실패 시, 프로그램 폴더에 xlsx.full.min.js 파일이 있는지 먼저 확인하세요.
- 그래도 어렵다면 엑셀 파일을 "다른 이름으로 저장 → CSV" 후 불러오세요.
