사용 안내

이 사이트는 수업용 웹 도구 런처입니다. 앱은 별도 설치 없이 브라우저에서 바로 실행됩니다.

  • 검색창에 키워드를 입력하면 도구가 자동으로 필터링됩니다.
  • 태그(예: 확률, 타이머)를 눌러 관련 도구만 모아볼 수 있습니다.
  • 수업 중에는 전체화면을 권장합니다.
  • 새 도구를 추가하려면 /apps/도구이름/index.html로 파일을 올린 뒤, 아래 데이터 목록에 한 줄 추가하면 됩니다.
